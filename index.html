Using the gallery

Select a template to try its controls. Use the Color palette menu in the top bar to choose a scheme. Style controls change shapes, borders, fills, panels and icons. Download ZIP includes the selected scheme, styling, editable source files and BUILD-INSTRUCTIONS.md.

Download any extra elements, then use Project prompt underneath Elements to copy the prompt for a new chat. Upload the ZIPs and your content together. Element downloads are named additional-element-… so the chat can identify them.

Cards marked “Study” are interactive previews without downloads.
